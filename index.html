Audio ML · classification

Shipped

Infant State Recognition from Cry Audio

Classifies infant cry audio into 8 need states: hungry, tired, belly pain, burping, scared, lonely, discomfort and cold/hot. 511 cleaned clips become a 218-dim librosa feature vector (MFCC, delta-MFCC, log-mel, chroma, spectral contrast, tonnetz, ZCR, RMS) fed to a cost-sensitive Random Forest (300 trees, balanced class weights, 5-fold stratified CV).

Test accuracy
81.6%
Macro F1
32.0%

Honest read: the dataset is heavily imbalanced (~75% "hungry"), so accuracy flatters the model. Macro F1 is the metric I'm working to improve. Next: data augmentation and a CNN on log-mel spectrograms.

  • Python
  • librosa
  • scikit-learn
  • Random Forest
  • NumPy
  • Pandas

ML · course project

Shipped

Flight Delay Risk Prediction

Predicts, the night before departure, whether a New York flight will arrive 15+ minutes late, using 336,776 departures from 2013 (nycflights13). Past-only features with a leakage test, a chronological train/validation/test split, logistic regression vs XGBoost, Platt calibration with rolling recalibration, and a what-if rescheduling analysis.

PR-AUC (XGBoost)
0.468
Prior baseline
0.335

Honest read: December test set. Rolling recalibration cut calibration error (ECE) from 0.102 to 0.047, but at precision ≥ 0.5 recall is only 0.035. There's no weather data, which limits day-ahead accuracy.

  • Python
  • XGBoost
  • scikit-learn
  • Pandas
  • Jupyter
